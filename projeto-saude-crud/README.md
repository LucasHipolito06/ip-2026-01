# Sistema de Cadastro de Pacientes

Projeto individual desenvolvido em Go, inspirado no código modelo `servidorHTTP`, com implementação de CRUD no contexto da saúde.

## Tema

Sistema simples para cadastro e gerenciamento de pacientes de uma centro de saúde.

## Funcionalidades

- Cadastrar pacientes
- Listar pacientes
- Atualizar pacientes
- Excluir pacientes

## Tecnologias utilizadas

- Go
- PostgreSQL
- HTML
- CSS
